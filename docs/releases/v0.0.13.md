# SwitchFix v0.0.13

Fixes for all three open reports, plus a revert regression found while auditing them.

## Fixes

- **Dictionaries are found in builds made with newer Swift toolchains ([#14](https://github.com/rundax/SwitchFix/issues/14)).** With Swift 6.4 and later, source builds put the dictionaries where macOS does not look, so nothing was corrected. The build now places them correctly for both bundle layouts, and it fails instead of producing an app that cannot correct.
- **Correction keeps working after switching layouts with Globe (🌐) ([#15](https://github.com/rundax/SwitchFix/issues/15)).** Typing is no longer ignored until the next mouse click. A word whose first letters were typed before SwitchFix was ready is now left as typed instead of being half-corrected (`ghbdtn` → `gпривет`).
- **Caps Lock revert works again after a correction that switched the layout.** Since v0.0.12, reverting such a correction did nothing.

## New features

- **Single-modifier shortcuts ([#16](https://github.com/rundax/SwitchFix/issues/16)).** In Settings → Shortcuts, click a shortcut and tap Control, Option, Shift, or Command on its own. Then choose Left, Right, or Either Side. A tap types no character, so nothing extra has to be deleted. Combinations such as Ctrl+C work as before, and holding the key longer than half a second does not trigger the shortcut.

## Documentation

- The README and website described Cmd+Z as SwitchFix's undo. Revert uses Caps Lock (configurable); Cmd+Z uses the undo of the app you are typing in.

## Install or update

Download **SwitchFix-arm64.app.zip** for Apple Silicon or **SwitchFix-intel.app.zip** for Intel. macOS 13 or later is required.

Builds are ad-hoc signed and are not notarized by Apple. macOS may require **Privacy & Security → Open Anyway** on first launch. After updating, you may need to grant Accessibility and keyboard input permissions again. See the [setup guide](https://rundax.github.io/SwitchFix/tutorial/).
