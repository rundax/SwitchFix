How SwitchFix Works Under the Hood

Simple, reliable, deterministic keyboard layout switching.

1

Non-blocking Buffer

Keystrokes pass through untouched to the active app while a lightweight buffer watches for word boundaries (space, enter, punctuation).

2

Dictionary Verification

When a boundary is hit, the word is tested against local bloom filters and frequency dictionaries across configured alternate layouts.

3

Atomic Replacement

If a match is found in an alternate language, SwitchFix switches the macOS input source, deletes mistyped letters, and outputs the correct text.
