# SwitchFix v0.0.12

More control over automatic correction, with safer handling of words typed in the wrong layout.

## New features

- **Personal exceptions:** add words in Settings → Personal Exceptions to keep them exactly as typed during automatic correction. Hotkey and layout-switch corrections remain available when you explicitly request them.
- **Correct earlier words together:** when a later word confirms the intended layout, SwitchFix can also correct earlier words in the same uninterrupted typing run. It stops at Enter, uncertain text, or a protected exception.

## Improvements

- Automatic correction works between English and one selected Cyrillic layout, avoiding unwanted Russian-to-Ukrainian or Ukrainian-to-Russian conversions.
- Apple keyboard layouts are classified by their primary language instead of every language their character set can represent.
- More reliable correction bookkeeping when typing is interrupted, text is deleted, or a correction cannot be emitted.
- Added a reproducible layout benchmark, frozen test corpora, and CI regression gates to catch correction regressions before release.
- Added `vnc` to the English allow list.

## Install or update

Download **SwitchFix-arm64.app.zip** for Apple Silicon or **SwitchFix-intel.app.zip** for Intel. macOS 13 or later is required.

Builds are ad-hoc signed and are not notarized by Apple. macOS may require **Privacy & Security → Open Anyway** on first launch. After updating, you may need to grant Accessibility and keyboard input permissions again. See the [setup guide](https://rundax.github.io/SwitchFix/tutorial/).

## Known issues

- [#14](https://github.com/rundax/SwitchFix/issues/14): source builds with newer Swift toolchains can package dictionary binaries in the wrong bundle directory.
- [#15](https://github.com/rundax/SwitchFix/issues/15): switching layouts with Globe can leave correction paused until a mouse click.
- [#16](https://github.com/rundax/SwitchFix/issues/16): modifier-only correction shortcuts are not supported yet.
